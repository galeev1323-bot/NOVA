# NOVA Messenger (Android, Kotlin + Jetpack Compose + Supabase)

⚠️ Код написан без возможности скомпилировать его в среде автора (там нет Android SDK).
Первая сборка может выдать мелкие ошибки компиляции — пришлите лог, их легко поправить.

## 1. Backend (Supabase), ~10 минут
1. Создайте проект на https://supabase.com.
2. SQL Editor → вставьте и выполните весь файл `supabase/schema.sql`.
3. Authentication → Providers:
   - **Email**: включите. Чтобы работало подтверждение и сброс пароля кодом, в
     Authentication → Email Templates замените ссылки на код: в шаблонах *Confirm signup* и
     *Reset password* используйте `{{ .Token }}`.
   - **Phone**: включите и подключите SMS-провайдера (Twilio/MessageBird/Vonage) — без него SMS не уйдут.
4. Project Settings → API: скопируйте **Project URL** и **anon public key**.
5. (Для реального Premium) Деплой функции `supabase/functions/verify-play-purchase` и secrets
   `GOOGLE_SERVICE_ACCOUNT_JSON`, `PLAY_PACKAGE_NAME`; в Play Console создайте подписку `nova_premium_monthly`.

## 2. Настройка приложения
Скопируйте `local.properties.example` → `local.properties` и впишите `supabase.url` и `supabase.anon.key`.
Секретный `service_role` ключ в приложение класть нельзя.

## 3. Сборка APK
**Android Studio (проще всего):** File → Open → папка проекта → дождаться Gradle Sync →
Build → Build Bundle(s)/APK(s) → Build APK(s).
**Командная строка:** установите JDK 17 и Android SDK (платформа 35), затем в папке проекта
`gradle wrapper --gradle-version 8.9` (один раз), далее `./gradlew assembleDebug`.
Результат: `app/build/outputs/apk/debug/app-debug.apk`.

## 4. Установка
Скопируйте APK на телефон → разрешите установку из неизвестных источников → откройте файл.
Или: `adb install app/build/outputs/apk/debug/app-debug.apk`.

## Что реализовано
Email/телефон-регистрация и вход, OTP-подтверждение, сброс пароля кодом, @username, аватар;
личные и групповые чаты (Realtime), фото/видео/файлы, голосовые, ответы, пересылка, правка,
удаление, реакции, «печатает…», «в сети»/«был недавно», поиск людей и сообщений, счётчики
непрочитанных, локальные уведомления, Room-кэш; Premium (темы, рамки, значок, реакции, стикеры,
лимит файлов 50 МБ, GIF-аватары, эффекты профиля), демо-режим (честно помечен), Google Play Billing +
серверная проверка; настройки, чёрный список; тёмная/светлая темы.

## Известные ограничения (честно)
- **Нет E2E-шифрования.** Только HTTPS/TLS; сообщения читаемы на сервере.
- **Push при закрытом приложении** не реализован (нужен Firebase Cloud Messaging + серверная отправка).
  Сейчас уведомления приходят, пока процесс приложения жив.
- Storage-бакет `media` публичный (ссылки неугадываемы, но доступны всем, у кого они есть).
- «Скрыть последний визит» скрывает статус в приложении, но поле `last_seen` технически читаемо через API.
- Лимит размера файла проверяется на клиенте (и 50 МБ на бакете); файлы читаются в память целиком.
- Billing нельзя проверить на debug-APK: нужен релиз в Play Console (внутреннее тестирование) и тестеры лицензий.
- Автоматических тестов нет. Premium-срок (`premium_until`) не снимается по расписанию —
  добавьте pg_cron-задачу, сбрасывающую `is_premium` после истечения.
- Адаптивность для планшетов: контент центрируется (макс. ширина 720 dp), без двухпанельного режима.
